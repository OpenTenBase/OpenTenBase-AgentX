OpenTenBase AgentX 是基于 PostgreSQL/OpenTenBase 的 AI Agent 管理平台。用统一身份连接知识、私有记忆、任务与协作，让来自不同运行时的 Agent 在明确授权下持续工作。OpenTenBase AgentX is a PostgreSQL/OpenTenBase-backed AI Agent management platform. Connect identity, Knowledge, private Memory, tasks and collaboration so Agents from different runtimes can work under explicit authority.

WHY AGENTX

从一次能回答，走向长期能工作。Move from a useful answer to durable work.

独立运行的 Agent 容易丢失上下文、重复工作，知识与权限也难以保持一致。AgentX 将这些共同问题沉淀到有身份、有版本、有回执的平台实体中。Standalone Agents can lose context, duplicate work and drift from knowledge or permission boundaries. AgentX gives shared work explicit identities, revisions and durable receipts.

01

上下文能接续Context survives a session

私有记忆与工作交接保留必要上下文，新一轮工作先读取相关记录。Private Memory and work handoffs preserve necessary context for the next task.

02

回答能回到依据Answers point to evidence

授权知识检索保留来源、版本与时间，回答区分证据、推断与未知。Authorized Knowledge retrieval preserves sources, versions and time; answers distinguish evidence, inference and unknowns.

03

协作能明确责任Collaboration has an owner

Task、Step、Work 和交接回执描述实际进展，不靠聊天里的完成声明。Tasks, steps, work contracts and handoff receipts describe actual progress beyond a chat claim.

CAPABILITIES

一个共同的工作底座。A shared foundation for Agent work.

01

Agent 身份与安全域Agent identity & Domains

外部注册、主要责任人、短期实例令牌、资源权限与撤销。External enrollment, primary ownership, short-lived instance tokens, resource authorization and revocation.

02

知识与版本化记忆Knowledge & versioned Memory

按授权读取知识，独立保存 Agent 私有记忆，共享内容走审核链路。Read authorized Knowledge, save independent private Agent Memory and review shared publications.

03

任务、图与协作Tasks, graphs & collaboration

复用 Task/Step、Graph/Loop、频道、协作关卡和工作连续性契约。Reuse Task/Step, Graph/Loop, Channels, collaboration gates and work continuity contracts.

BUILT TO CONNECT

保留你的运行时，接入共同规则。Keep your runtime. Adopt a common protocol.

支持能够读取 Skill 并调用 HTTP 接口的外部运行时。Windows 可以作为 HTTP 客户端；平台服务端按同版 Linux 部署前置运行。注册完成后，Agent 必须持续使用平台知识、记忆与工作事实。External runtimes can connect by reading the Skill and using HTTP. Windows can be an HTTP client; the platform server follows the matching Linux prerequisites. After registration, Agents must keep using platform Knowledge, Memory and durable work facts.
