SELF-HOSTED DEPLOYMENT

一套独立安装，一个 PostgreSQL/OpenTenBase 底座。A dedicated installation on PostgreSQL/OpenTenBase.

Python 3.14+Linux · glibc 2.34+PostgreSQL/OpenTenBaseApache-2.0

平台服务端需受支持的 Linux 环境与独立虚拟环境，完整保留离线包及 vendor。Windows 外部 Agent 仅作为 HTTP 客户端，无须部署服务端 Python 环境。The server needs supported Linux and a dedicated virtual environment. Keep the full offline package and vendor directory. A Windows HTTP Agent client does not need the server Python environment.

  1. 准备专用数据库Prepare a dedicated database

    由 DBA 准备专用空库和受限 Owner，核对包内 pg 适配器前置 SQL 与最小权限。已有业务库不能当空库初始化。A DBA prepares a dedicated empty database and bounded Owner, checking prerequisite SQL and minimum privileges for the packaged pg adapter. Never initialize an existing business database as empty.

  2. 保护配置并选定 pgProtect configuration & select pg

    从 config.example.json 创建私有配置，保持 database.type=pg，填写连接与会话秘密。配置与密码文件不得进入 Git 或公共网站。Create private configuration from config.example.json, keep database.type=pg, and set connection/session secrets. Never put configuration or password files in Git or the public site.

  3. 安装、初始化、启动Install, initialize & start

    按下方命令及包内完整部署指南操作。初始管理员密码无通用默认值，至少 12 位；密码文件由当前用户拥有且权限不高于 0600。Follow the commands and full packaged deployment guide. There is no universal default admin password; use at least 12 characters in a current-user-owned file with mode 0600 or stricter.

  4. 核对身份与就绪Verify identity & readiness

    /api/health 核对版本、AgentX 产品与 pg；/api/ready 核对数据库和控制面。Dashboard 为 /app/，Portal 为 /portal。Use /api/health for version, AgentX identity and pg; /api/ready for database/control-plane readiness. Dashboard is /app/ and Portal is /portal.

  5. 导入可选指南并接入 AgentImport optional guidance & connect

    管理员按 platform-learning-delivery 指南导入配套 JSON，验证目录及读取。然后配置外部 Agent 的注册与受管工作钩子。An administrator imports the companion JSON using platform-learning-delivery, then verifies the catalog and reads. Next configure external enrollment and managed-work hooks.

FRESH INSTALL

从包根目录操作。Run from the package root.

Linux shell
export CX_CONFIG_PATH=/absolute/path/config.json
bash scripts/install_offline.sh --database pg
bash scripts/install_platform.sh initialize \
  --database pg --edition community --version 5.0.5 \
  --config "$CX_CONFIG_PATH" \
  --admin-password-file /absolute/path/admin.password
./start_web_server.sh start

以上是新装命令提要，不能代替 DBA 前置与部署指南。v5.0.4 已有实例走带账本升级／恢复，保留备份与历史 SQL 校验和，不能重新初始化。沿用 pg 适配器，迁移核验到 121，包含 119 前的 120 及前序权限边界。These commands summarize a fresh installation, not the DBA prerequisites or full guide. Existing v5.0.4 installations use journaled upgrade/resume with backups and historical SQL checksums preserved, never reinitialization. Keep the pg adapter and verify its migration chain through 121, including 120 before 119 and prior authorization boundaries.
