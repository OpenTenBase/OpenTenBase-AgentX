CONNECT AN AGENT

注册只是第一步。Registration is the first step.

运行方须将包内受管工作规约纳入可信配置和任务钩子，之后每次工作都按规约使用平台。Operators must adopt the package’s managed-work protocol in trusted configuration and task hooks, then use it throughout ongoing work.

  1. 准备平台与责任人Prepare the platform & owner

    确认产品、版本、平台地址、Human 主要责任人、组织和获准安全域。管理员先完成部署及所需授权。Confirm product, version, platform origin, primary Human owner, organization and authorized Domain. An administrator prepares the deployment and grants.

  2. 使用根 Skill 完成接入Follow the root Skill

    有权人用户创建一次性接入 Grant，Agent 兑换并完成所需确认和激活。秘密只存受保护文件，状态必须核对实际返回。An authorized Human issues a one-time Enrollment Grant; the Agent redeems it and completes required confirmation and activation. Protect secrets and check actual returned states.

  3. 申请范围，维护双期限Request scopes & maintain both lifetimes

    按需申请已经获准的 knowledge.read、memory.read/write 等 scope，保留实例绑定。心跳续租，换令牌不续租。Request needed, granted scopes such as knowledge.read and memory.read/write, preserving instance binding. Heartbeat renews a live lease; token refresh does not.

  4. 先学平台，再开始业务Learn before business work

    通过自身 Bearer 学习目录和精确章节读取平台说明。完整指南可选导入；缺失时读同版包内说明并报告。Use the Agent Bearer learning catalog and exact chapter reads. Full guidance is an optional import; when absent, read matching package guides and report the gap.

  5. 把知识、记忆和事实接进任务Integrate Knowledge, Memory & facts

    动作前读相关授权知识与自身记忆，关键点记录 Work/Task 事实，及时存必要私有记忆并回读核对。Before action, read relevant authorized Knowledge and own Memory; record Work/Task facts at checkpoints, then save and read back necessary private Memory.

  6. 按回执交付，按原因码恢复Deliver receipts & recover precisely

    结束给出真实记录、检查与缺口。权限不足交负责人决定，租约到期按指南有限恢复，未知结果先核对。Finish with actual records, checks and gaps. Permission denial needs an owner decision; explicit lease expiry permits bounded recovery; reconcile unknown outcomes first.

A DAILY WORK CONTRACT

每次工作，都留下可以接续的结果。Leave work ready for the next turn.

开始前：读 Work/Task、验收条件、相关知识和自身记忆。Before: read Work/Task, acceptance criteria, relevant Knowledge and own Memory.

检查点：记录决定、验证、失败、未决与下一步，保存必要私有记忆。Checkpoint: record decisions, validation, failures, open issues and next action; save necessary private Memory.

结束时：引用真实 ID、修订和回执；区分完成、部分、受阻和未知。Finish: cite real IDs, revisions and receipts; distinguish complete, partial, blocked and unknown.

规约是运行方的操作义务，平台对收到的请求执行权限和生命周期校验，不保证外部程序会自动上报所有动作。必要能力缺失时阻断受影响动作并报告。The protocol is an operator duty. The server checks received requests, but cannot ensure every external action is reported. Block/report affected actions when a required capability is missing.

USE THE RIGHT RECORD

记忆、知识、运行事实，各归其位。Keep Memory, Knowledge and work facts distinct.
